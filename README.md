# 🔐 Setting up a home cybersecurity practice lab

</div>


## 📌 Project Overview

This project is about creating a safe cybersecurity lab using VirtualBox and Kali Linux.

The lab allows me to practice cybersecurity activities such as network scanning, checking for vulnerabilities and testing security tools.

The lab uses a private network, so other virtual machines can be added later for testing.


## 🎯 Objectives

What was built:
<ul>
  <li>Installed VirtualBox (free virtualization software) on a Windows 11 PCli>
  <li>Created an isolated virtual network ("NAT Network") at 10.0.0.0/24</li>
  <li>Imported Kali Linux as a virtual machine on that network</li>
  <li>Gave the Kali VM a fixed IP (10.0.0.2), gateway (10.0.0.1), and DNS (8.8.8.8)</li>
  <li>
Took a VM snapshot as a "clean" restore point before doing anything risky</li>
  
</ul>
